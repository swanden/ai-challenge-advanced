# CLAUDE.md — notes-api

HTTP-сервис заметок на Go. Только стандартная библиотека: `net/http`, `log/slog`,
`encoding/json`. Внешних зависимостей нет и добавлять нельзя. Роутинг — `http.ServeMux`
с method-шаблонами (`"GET /notes/{id}"`), сторонние роутеры запрещены.

Модуль: `github.com/swanden/ai-challenge-advanced`, каталог задания
`week-1/task-5/notes-api/`. Внутренние пакеты импортируются полным путём модуля.

## Слои

- `cmd/notes-api` — точка входа: сборка зависимостей, запуск, graceful shutdown. Логики нет.
- `internal/note` — домен: модель `Note`, бизнес-правила в `Service`, интерфейсы `Repository`,
  `IDGenerator`, `Clock`. Про HTTP и хранилище не знает.
- `internal/storage` — реализации `note.Repository` (сейчас `MemoryRepo`).
- `internal/httpapi` — транспорт: разбор запроса, вызов сервиса, ответ. Бизнес-логики нет.

Поток: хендлер → `note.Service` → `note.Repository`. Хендлер в репозиторий напрямую не ходит.

## Обязательные правила

1. `context.Context` первым аргументом у всего, что делает I/O; в хендлере берётся
   `r.Context()` и пробрасывается насквозь. Свой контекст внутри метода не создавать.
2. Время и идентификаторы — только через `s.clock.Now()` и `s.ids.NewID()`, не напрямую.
   Время в UTC.
3. Валидация входных данных — в сервисе, не в хендлере. Хендлер транслирует доменную
   ошибку в статус.
4. Тело запроса — типизированная структура с json-тегами, не `map[string]any`.
5. Ошибки различаются через `errors.Is` и мапятся явно: `ErrNotFound` → 404,
   `ErrEmptyText` → 400, иначе → 500. Наружу — `errorResponse`, не `err.Error()`.
6. HTTP-статусы — именованными константами (`http.StatusNotFound`), не числами.
7. Ошибки не проглатывать: сбой кодирования логировать через `slog`.
8. Доступ к общему состоянию — под мьютексом.
9. Конструкторы называются `NewXxx`, доменные ошибки — переменные с префиксом `Err`.
10. Тесты — table-driven, зависимости подменяются дублями, ошибки сверяются через `errors.Is`.

Образцы для всего перечисленного лежат в самом коде: `Service.Create` в
`internal/note/note.go`, хендлер `get` в `internal/httpapi/handler.go`, тест в
`internal/note/note_test.go`. Смотреть их, а не выдумывать свой стиль.

## Антипаттерны

Метод с I/O без `ctx`; `time.Now()` мимо `Clock`; `map[string]any` для тела запроса;
магические числа статусов; `http.Error(w, err.Error(), ...)`; проглоченная ошибка;
бизнес-логика в хендлере; правка чужих тестов ради зелёной сборки; внешние зависимости.
