# CLAUDE.md — tasks-api

Учебный HTTP-сервис задач на Go. Песочница для тренировки работы с код-ассистентом.

## Стек

Только стандартная библиотека: `net/http` для транспорта, `log/slog` для логов,
`encoding/json` для сериализации. Внешние зависимости не добавлять.
Роутинг — `http.ServeMux` с method-шаблонами (`"GET /tasks/{id}"`).

## Архитектура

Зависимости направлены внутрь, к домену:

- `cmd/tasks-api` — точка входа, только сборка зависимостей и запуск.
- `internal/task` — домен: модель `Task`, правила, потокобезопасное хранилище `Store`.
  Про HTTP не знает.
- `internal/httpapi` — транспорт: разбор запроса, вызов домена, ответ. Бизнес-логики нет.

Поток: хендлер → `task.Store`. Хендлер бизнес-правил не реализует.

## Обязательные паттерны

`context.Context` первым аргументом у методов, делающих I/O; в хендлере берётся
`r.Context()` и пробрасывается в домен.

Тело запроса — типизированная структура с json-тегами, а не `map[string]any`.

Валидация входных данных — в домене, хендлер только транслирует доменную ошибку в статус.

Ошибки различаются через `errors.Is` и мапятся на статусы явно: `ErrNotFound` → 404,
`ErrEmptyTitle` → 400, иначе → 500. Наружу отдаётся безопасное сообщение в формате
`errorResponse`, а не `err.Error()`.

HTTP-статусы — только именованными константами (`http.StatusNotFound`), не числами.

Ошибки не проглатываются: сбой кодирования логируется через `slog`.

Доступ к общему состоянию — под мьютексом.

## Антипаттерны

- Метод с I/O без `context.Context` первым аргументом.
- `map[string]any` для тела запроса и type assertion без проверки `ok`.
- Магические числа статусов вместо `http.StatusXxx`.
- `http.Error(w, err.Error(), ...)` — утечка внутренней ошибки наружу.
- Проглоченная ошибка без проверки и лога.
- Бизнес-логика в хендлере; работа с картой задач мимо `Store`.
- Внешние зависимости и сторонние роутеры.
