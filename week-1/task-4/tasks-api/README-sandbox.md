# tasks-api — подопытный проект Дня 4

Учебный HTTP-сервис задач на Go. Специально небольшой и на стандартной библиотеке,
чтобы локальной модели хватало контекста, а нарушения конвенций были заметны.

```
tasks-api/
├── CLAUDE.md                  правила проекта — подавались модели как системный промпт
├── go.mod                     module tasksapi
├── cmd/tasks-api/main.go      точка входа, порт 8090
└── internal/
    ├── task/task.go           домен: Task, Store (Create, Get, SetDone, List)
    └── httpapi/handler.go     транспорт: POST /tasks, GET /tasks, GET /tasks/{id}, PATCH /tasks/{id}
```

Здесь лежит **исходное состояние** — то, с которого начинался каждый прогон. Результаты
прогонов не смёржены: они в `../evidence/` как артефакты, потому что ни один не дал
работающего кода.

## Запуск

```
go build ./... && go run ./cmd/tasks-api

curl -X POST -d '{"title":"купить хлеб"}' localhost:8090/tasks
curl localhost:8090/tasks
curl localhost:8090/tasks/1
```
