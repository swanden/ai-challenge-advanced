Полный цикл проверки: Уровень 1 (код-тесты) → ворота → Уровень 2 (smoke через браузер) → единый отчёт.

Аргументы: $ARGUMENTS — путь к задаче (по умолчанию `week-1/task-3/notes-api`).

Ты — оркестратор. Субагенты не умеют вызывать субагентов, поэтому связку держишь ты.
Не доверяй формулировкам профилей: ворота и наличие артефактов проверяй сам, своими командами.

## Подготовка

1. Определи TASK (из $ARGUMENTS или дефолт) и REPO_ROOT (корень git).
2. Заведи каталог прогона: `RUN=$REPO_ROOT/$TASK/../qa-runs/$(date +%Y-%m-%d-%H%M)`, создай его и
   подкаталог `screenshots`, дай права на запись (`chmod -R 777 "$RUN"` — Playwright MCP пишет
   из-под пользователя контейнера).
3. Проверь, что Playwright MCP подключён (`/mcp` показывает playwright: connected). Не подключён —
   останови цикл и скажи, что нужно `claude mcp add playwright npx @playwright/mcp@latest`.

## Уровень 1

4. Запусти субагента `test-writer` через тул Task, передав TASK. Он сам выберет, что покрывать,
   напишет тесты, прогонит и проверит мутациями. Сохрани его отчёт в `$RUN/level1.md`.

## Ворота (проверяешь сам, не со слов профиля)

5. Из REPO_ROOT прогони: `go build ./$TASK/...`, `go vet ./$TASK/...`, `gofmt -l $TASK`,
   `go test ./$TASK/... -count=1`. Хоть одно красное — цикл останавливается, Уровень 2 НЕ
   запускается: тыкать UI на сломанной сборке бессмысленно. Запиши результат ворот в отчёт.

## Поднять сервис

6. Собери и запусти бинарник в фоне: `go run ./$TASK/cmd/notes-api &`, дождись готовности —
   опрашивай `http://localhost:8080/` до кода 200 (до 30 с). Запомни PID для остановки.

## Уровень 2

7. Запусти субагента `smoke-runner` через Task, передав ему: путь к `docs/smoke-scenarios.md`,
   базовый URL `http://localhost:8080/`, каталог для скриншотов `$RUN/screenshots` (абсолютный).
   Сохрани его отчёт в `$RUN/level2.md`.

## Завершение

8. Погаси сервис (kill PID).
9. Собери единый отчёт `$RUN/report.md`: вердикт Уровня 1 (покрытие было/стало, мутации),
   результат ворот, вердикт Уровня 2 (сколько сценариев прошло, ссылки на скриншоты),
   и общий итог. Зелёный общий вердикт запрещён, если: ворота красные, нет профилей покрытия,
   нет скриншотов, или smoke-runner не подтвердил шаги снапшотами.

Каждый переход между стадиями явно проговаривай: какая стадия закончилась и какая начинается.
