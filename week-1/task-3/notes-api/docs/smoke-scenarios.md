# Smoke-сценарии — notes-api

Пользовательские сценарии для прогона через Playwright MCP по веб-интерфейсу.
Базовый URL: `http://localhost:8080/`. Селекторы — по `data-testid`.

## S1. Создание заметки

1. Открыть `/`.
2. В поле `note-input` ввести «Купить молоко».
3. Нажать `add-button`.
4. **Ожидание:** в списке `notes-list` появился элемент `note-item` с текстом «Купить молоко»;
   поле ввода очистилось; блок `empty` скрыт.

## S2. Создание нескольких и проверка списка

1. Открыть `/`.
2. Создать три заметки: «Хлеб», «Сыр», «Чай» (каждую через ввод + `add-button`).
3. **Ожидание:** в `notes-list` ровно три элемента `note-item` с этими текстами в порядке создания.

## S3. Удаление заметки

1. Открыть `/` (в списке есть хотя бы одна заметка из предыдущих сценариев или создать одну).
2. У первого `note-item` нажать `delete-button`.
3. **Ожидание:** этот элемент исчез из `notes-list`; число элементов уменьшилось на один.

## S4. Валидация пустого текста

1. Открыть `/`.
2. Не вводя текста (или введя только пробелы), нажать `add-button`.
3. **Ожидание:** новый `note-item` не появился; в блоке `error` показано сообщение
   «Текст заметки обязателен»; запрос на создание сервер отклонил (400).

## S5. Пустое состояние после удаления всех

1. Открыть `/`.
2. Удалить все заметки по очереди кнопками `delete-button`.
3. **Ожидание:** `notes-list` пуст; показан блок `empty` с текстом «Пока нет заметок».
