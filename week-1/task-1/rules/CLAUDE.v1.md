# CLAUDE.md — notes-api

Это небольшой HTTP-сервис заметок на Go.

## Стек
- Go
- стандартная библиотека (net/http), без внешних зависимостей

## Как писать
- пиши идиоматичный Go
- следуй слоёной архитектуре, которая уже есть в проекте
- покрывай код тестами

## Структура
- `cmd/` — точка входа
- `internal/` — внутренние пакеты
